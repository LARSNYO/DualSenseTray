# DualSenseTray

Приложение для системного трея Windows, отображающее уровень заряда батареи и статус зарядки геймпада **Sony DualSense** (PlayStation 5).

## 📖 Описание

`DualSenseTray` — лёгкое приложение, работающее в фоне и автоматически определяющее подключение контроллера DualSense. В трее отображается иконка батареи, которая визуально показывает текущий уровень заряда, а всплывающая подсказка информирует о статусе устройства.

## ✨ Возможности

- 🔋 **Визуальная индикация заряда** — иконка батареи в трее с цветовой кодировкой:
  - 🟢 зелёный — идёт зарядка (с молнией)
  - 🔴 красный — заряд ≤ 20%
  - 🟠 оранжевый — заряд ≤ 50%
  - ⚪ белый — заряд > 50%
- 🔄 **Автоматическое определение** контроллера (проверка каждые 3 секунды)
- 🔌 **Отслеживание отключения** — при потере связи иконка меняется на «ошибка»
- 📊 **Всплывающая подсказка** с уровнем заряда и статусом
- 🖱️ **Контекстное меню** для выхода из приложения
- 🪶 Работает без видимого окна — только иконка в системном трее

## 🧩 Требования

- **ОС:** Windows 10 / Windows 11 (x64)
- **.NET:** .NET 6 или выше (Windows Forms)
- **Библиотека:** [DualSenseAPI](https://github.com/nharrer/DualSenseAPI) для работы с контроллером
- **Контроллер:** Sony DualSense (PS5), подключённый по USB или Bluetooth
